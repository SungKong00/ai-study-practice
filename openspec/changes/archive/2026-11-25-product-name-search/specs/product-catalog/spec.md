## ADDED Requirements

### Requirement: 상품명으로 목록 검색

시스템은 선택적 `name`이 있으면 대소문자와 앞뒤 공백을 포함해 이름 전체가 같은 상품 모두를 기존 목록 정렬과 응답 형식으로 반환해야 한다(SHALL). 이름이 생략되면 전체 목록을 반환해야 한다(MUST). 빈 값·공백만 있는 값·반복한 값은 HTTP 400으로 거부해야 한다(MUST).

#### Scenario: 이름 일치와 정렬
- **WHEN** 노트 두 건과 노트북 한 건에서 노트를 가격순으로 검색한다.
- **THEN** 노트 두 건만 가격순으로 반환하고 가격 동률은 id 오름차순이다.

#### Scenario: 불일치
- **WHEN** 입력과 정확히 같은 이름이 없다.
- **THEN** HTTP 200과 빈 배열을 반환한다.

#### Scenario: 잘못된 이름
- **WHEN** name을 빈 값, 공백만 있는 값이나 두 번 이상 전달한다.
- **THEN** HTTP 400으로 응답한다.
