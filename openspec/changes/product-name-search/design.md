## Context

목록 컨트롤러가 중복 쿼리 값을 보존하고 승인된 정렬만 서비스에 전달한다.

## Goals / Non-Goals

등록된 이름을 원문 그대로 비교한다. 부분 일치와 대소문자 변환은 지원 범위 밖이다.

## Decisions

컨트롤러에서 원본 name 값과 개수를 검증한다. 서비스가 조회 조건에 맞게 기존 전체 조회 또는 이름 동등 비교 파생 쿼리를 선택하고 동일한 정렬을 전달한다.

## Risks / Trade-offs

문자열 비교 규칙은 DB 설정에 따라 달라질 수 있어 현재 지원하는 H2에서 대소문자와 앞뒤 공백을 검증한다.
