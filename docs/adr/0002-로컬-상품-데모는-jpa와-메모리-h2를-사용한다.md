# 로컬 상품 데모는 JPA와 메모리 H2를 사용한다

## Context and Problem Statement

첫 상품 등록·목록 조회 기능을 만들며 여러 API가 공유할 저장 방식을 정해야 한다. 기존 ADR에는 애플리케이션 저장 방식의 결정이 없다. 사용자는 Spring Data JPA와 메모리 H2를 선택했고, 앱 재시작 시 데이터가 초기화되는 구성을 선택했다.

## Considered Options

- 메모리 H2: 별도 DB 파일 없이 실행하고 재시작 시 초기화한다.
- 파일 H2: 재시작 뒤에도 데이터를 보존하지만 파일 경로와 데이터 정리가 필요하다.

## Decision Outcome

단일 Spring Boot 애플리케이션에서 Spring Data JPA로 상품을 저장하고, 로컬 데모와 테스트에 메모리 H2를 사용한다. 데이터는 프로세스 종료 시 사라지며 앱 시작 시 스키마를 새로 만든다. 외부 데이터베이스나 DB 설치·접속 설정은 추가하지 않는다.

### Consequences

Good, because 외부 DB를 준비하지 않고 API에서 저장·조회까지 연결해 개발 흐름을 실습할 수 있다.
Bad, because 재시작하면 데이터가 사라지고 실제 운영 DB의 SQL·트랜잭션 차이까지 검증하지는 못한다.
