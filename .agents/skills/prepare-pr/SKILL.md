---
name: prepare-pr
description: “PR 올려줘”, “PR 준비해줘”, “PR 초안 써줘” 요청에서 브랜치 변경을 검토하고 저장소 PR 양식으로 제출하거나 초안을 보여준다.
---

1. 대상 브랜치와 현재 브랜치의 공통 조상부터 커밋·diff를 확인하고 작업 트리도 확인한다. 이슈와 무관한 커밋이 섞였거나 제출 범위가 모호하면 해당 변경을 짚고 범위를 정한 뒤 진행한다.
2. Spring 코드·설정 변경은 [Spring 변경 리뷰](../spring-change-review/SKILL.md)를 읽고 제출할 diff에 적용한다. 지적의 근거와 사용자 영향을 제시한다. 미결 정책이나 수정이 필요한 회귀는 개발자의 결정 또는 수정 후 진행한다. 수정한 경로는 다시 검토한다.
3. 리뷰 후 [PR 템플릿](../../../.github/pull_request_template.md)을 읽고 최종 diff 기준으로 채운다. 확인한 이슈 번호·명세, 사용자에게 달라지는 동작, 검토한 조건과 실제 테스트 결과를 적는다. 미실행 검증은 구분한다. 결정이 필요할 때만 리뷰어에게 구체적인 질문을 남긴다.
4. 준비·초안 요청이면 제목과 본문을 반환한다. 제출 요청이면 최종 검토한 커밋을 푸시하고 같은 head/base의 기존 PR을 확인해 생성하거나 갱신한다. 본문은 파일로 전달하고 PR 링크를 반환한다.
