[기능 요청 템플릿](../../../.github/ISSUE_TEMPLATE/feature.md)을 읽고 대화에서 합의한 내용으로 세 주석을 채운다. GitHub 선택 화면용 frontmatter는 본문에서 뺀다. 제목은 사용자가 기대하는 변화로 쓴다.

기존 동작은 기준 브랜치 같은 커밋의 `openspec/specs/product-*/spec.md`에서 해당 조건을 찾아 상품 구현과 대조한다. 누락되거나 충돌하는 조건은 확인 필요로 남긴다. 제보와 구현이 다르면 확인한 사실과 요청자의 경험을 본문에서도 구분한다. 이미 지원하면 사용법과 근거를 답한다. 완료 예시를 바꿀 제품 조건이 미정이면 그 조건을 먼저 질문한다. 초안 요청은 제목과 본문을 보여주고, 등록 요청이 있으면 같은 내용의 열린 이슈를 확인한 뒤 등록한다.
