---
name: commit-change
description: 커밋 요청 또는 PR 제출 전 변경을 목적별로 분리해 저장소 컨벤션으로 커밋한다.
---

현재 브랜치와 staged·unstaged·새 파일을 확인한다. 요청 범위만 파일 또는 hunk 단위로 선택하고 이미 stage된 다른 작업과 섞이면 분리할 때까지 커밋을 보류한다.
하나의 동작과 그 테스트·사용법은 함께, 독립적으로 되돌릴 변경은 따로 묶는다. 각 묶음의 staged diff를 검토하고 `type: 한글 내용`으로 커밋한다(예: `feat: 상품명 검색 지원`).
마지막에 base와 비교해 범위와 순서를 확인한다. 공유된 커밋 재작성은 명시적 요청이 있을 때만 진행한다.
